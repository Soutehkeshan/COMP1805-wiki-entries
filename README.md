# COMP1805 Natural Computing: Wiki Entries

My weekly wiki entries for **COMP1805 Natural Computing** at the University of Greenwich. Each folder has a README with my answers and observations, plus the code and figures behind them.

| Week | Topic | Contents |
|---|---|---|
| 1 | [No Free Lunch Theorem](Week%201%20-%20NFLT/) | The theorem and a real-world example of matching an algorithm to the problem |
| 2 | [Toy Problem](Week%202%20-%20Toy%20Problem/) | Random search on the Sphere function, and two [mini-project problems](Week%202%20-%20Toy%20Problem/#mini-project-problems) |
| 3 & 4 | [Dispersive Flies Optimisation (DFO)](Week%203%20%26%204%20-%20DFO/) | DFO on Sphere and Rastrigin, the effect of dimensionality and disturbance threshold, and DFO for image analysis (bright spots, motion, fading, multiple spots, symmetry) |
| 5 | [Genetic Algorithm (GA)](Week%205%20-%20GA/) | GA on a 30-D Sphere, and GA vs DFO on Sphere and Rastrigin |
| 7 | [Stochastic Diffusion Search (SDS)](Week%207%20-%20SDS/) | Summary of SDS and micro-features for image search |
